개발자가 작성하는 것
- 컴포넌트 함수
- JSX
- 이벤트 핸들러
- setState 호출
- state에 따라 어떤 UI가 보여야 하는지에 대한 선언

React가 내부적으로 관리하는 것
- state가 실제로 저장되는 위치
- state 업데이트 요청을 모아두는 큐
- 여러 업데이트를 언제 처리할지
- 컴포넌트를 언제 다시 실행할지
- 이전 UI와 새 UI를 비교하는 과정
- 실제 DOM을 언제 어떻게 바꿀지
- 컴포넌트 위치에 따라 state를 유지할지 초기화할지


-> React 내부에 state가 저장되어 있고, 컴포넌트가 렌더링될 때 React가 그 시점의 state 값을 넘겨준다.
